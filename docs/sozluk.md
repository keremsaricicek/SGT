# Domain Sözlüğü (TR / EN)

Kodda İngilizce terim, arayüzde Türkçe/İngilizce karşılık kullanılır.

| Türkçe | Kod (EN) | Anlamı |
|---|---|---|
| Oyuncu | Player | Casinoda oynayan kişi |
| Kişi / taraf | Party | Oyuncu ve otel misafirinin ortak kimliği |
| Misafir | Guest | Otelde kalan kişi |
| Oyuncu kartı | PlayerCard | Oyuncuyu makinede/masada tanıtan kart |
| Ziyaret | Visit | Oyuncunun casinoya bir gelişi |
| Oyun oturumu | PlayerSession | Bir makine/masada kart takılı geçen süre |
| Derecelendirme | Rating | Masa oyununda oyuncunun ortalama bahis ve süresinin kaydı |
| Kasa | Cage | Casinonun para/çip işlemleri yapılan yeri |
| Kasiyer vardiyası | CashierShift | Kasiyerin açılış–kapanış dönemi |
| Çip | Chip | Masa oyunlarında kullanılan değer jetonu |
| Masa float'ı | TableFloat | Masadaki çip stoku |
| Drop | Drop | Masa/makineden toplanan para |
| Canlı oyun / masa oyunu | LiveGame / TableGame | Rulet, blackjack, poker vb. |
| Masa | GamingTable | Canlı oyun masası |
| Pit | Pit | Masa grubu; pit boss yönetir |
| Slot makinesi | SlotMachine (EGM) | Elektronik oyun makinesi |
| Sayaç | Meter | Makinenin oyun sayısı, giren/çıkan tutar sayaçları |
| Makine olayı | MachineEvent | Kapı açıldı, hata, jackpot vb. |
| Jackpot | Jackpot | Büyük ödül |
| SMIB | SMIB | Makine içindeki arayüz kartı; veriyi dışarı verir |
| Slot veri kaynağı | SlotDataSource | NEXIO adaptörü, S Slot veya manuel giriş |
| Sadakat programı | Loyalty | Puan ve seviye sistemi |
| Puan | Points | Oyundan kazanılan sadakat puanı |
| Seviye | Tier | Oyuncunun sadakat seviyesi (ör. Gold) |
| İkram | Comp | Oyuncuya verilen ücretsiz hizmet (oda, yemek) |
| Host / PR | Host | Oyuncuyla ilgilenen casino personeli |
| Defter / hareket kaydı | Ledger / LedgerEntry | Silinemez para/değer hareketi kaydı |
| Ters kayıt | Reversal | Hatalı kaydı iptal eden karşı kayıt |
| Düzeltme kaydı | Adjustment | Gerekçeli düzeltme hareketi |
| Gerekçe kodu | ReasonCode | İşlemin neden yapıldığı |
| Dört göz onayı | MakerChecker | Bir kişi yapar, diğeri onaylar |
| Denetim kaydı | Audit | Kim, ne, ne zaman, hangi terminal |
| Terminal | Terminal | İşlemin yapıldığı bilgisayar/cihaz |
| Tesis | Property | Bir casino veya otel |
| Kiracı | Tenant | Müşteri şirket |
| Lisans | License | Hangi ürün/modülün açık olduğu |
| Rol | Role | Yetki grubu (ör. Pit boss) |
| Ekran yetkisi | ScreenPermission | Ekran için görebilir / işlem yapabilir |
| Süper admin | SuperAdmin | Rol ve yetki verebilen tek kullanıcı |
| Rezervasyon | Reservation | Otel oda ayırtma |
| Giriş / çıkış | CheckIn / CheckOut | Otele giriş / ayrılış |
| Oda | Room | Otel odası |
| Folio | Folio | Misafirin otel hesabı |
| Kat hizmetleri | Housekeeping | Oda temizlik durumu |
| Kapı kilidi | DoorLock | Oda kartı basan sistem |
| Para birimi | Currency | TRY, EUR, GBP, USD |
| Tutar | Money | Tutar + para birimi (value object) |
